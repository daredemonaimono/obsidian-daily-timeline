# Daily Timeline

Obsidian plugin that shows your daily notes as a Twitter-style timeline.

- Posting appends one line (`- HH:mm text`) to today's daily note. A new daily note is created when the date changes.
- Replying nests a line under the post (indented list item).
- Liking appends ` ♥` to the line.
- Scroll down to go back through older daily notes.
- Colors follow the current Obsidian theme.

Install with [BRAT](https://github.com/TfTHacker/obsidian42-brat) from `daredemonaimono/obsidian-daily-timeline`.

The daily note folder and date format default to the core Daily notes plugin's settings and can be changed in this plugin's settings.

## Development

```
npm install
npm run build
```
